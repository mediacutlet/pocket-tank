# Pocket Tank 中文上手指南

Pocket Tank 是一个能放在手心里的虚拟鱼缸。小鱼的高层行为由在 ESP32-S3 上运行的小型语言模型决定，模型会结合饥饿、精力、压力、好奇心、性格和周围环境，选择觅食、探索、休息、跟随伙伴或嬉戏等目标。日常运行可以离线完成。项目作者为 Strato Doumanis。[原项目说明](../README.md)

## 选择设备与安装

上游提供以下四块 Waveshare 开发板的固件。安装时按开发板的完整型号选择对应镜像，各板的显示、触摸和电源配置见硬件文档。

| 开发板 | 屏幕 | 配置 |
| --- | --- | --- |
| ESP32-S3-Touch-AMOLED-1.8 | 1.8 英寸 | 默认配置 |
| ESP32-S3-Touch-AMOLED-1.75C | 1.75 英寸圆屏 | sdkconfig.round |
| ESP32-S3-Touch-AMOLED-2.06 | 2.06 英寸手表屏 | sdkconfig.watch |
| ESP32-S3-Touch-AMOLED-2.16 | 2.16 英寸方屏 | sdkconfig.square |

[硬件配置与各板说明](BOARDS.md)

使用 Chrome 或 Edge 打开官方安装页，连接开发板，选择板型和串口，再按页面完成安装。设备上的网络设置用于检查和下载更新，小鱼的模型在本地运行。[官方安装页](https://pocketank.com/install/)

使用源码构建时，按仓库 README 和对应开发板文档配置 ESP-IDF、模型分区及签名密钥。模型文件与 tokenizer 配套使用。[构建与上板说明](bringup.md)

## 第一次进入鱼缸

新鱼缸会引导你为两条鱼苗选择外观、取名、放置气泡柱，并介绍照料方式。外观页面可以选择体型、鱼鳍、身体颜色和花纹。鱼苗会随着成长逐渐显现花纹和成鱼的鳍形。命名页面使用字母滚轮，放置气泡柱时可以沿缸底左右拖动。

## 日常操作

| 操作 | 效果 |
| --- | --- |
| 点水面，或从屏幕顶部向下划 | 投喂食物 |
| 点一条鱼 | 查看这条鱼的状态卡 |
| 点状态卡或 MORE | 打开成长与里程碑页面 |
| 在玻璃上按住手指约三秒 | 让信任你的鱼靠近 |
| 连续快速轻点三次 | 让附近的鱼受惊散开 |
| 双击玻璃 | 在手动关灯模式下切换灯光 |
| 拖动擦过玻璃 | 清理藻膜 |
| 横向划过水草 | 修剪划过位置的草叶 |
| 长按装饰 | 打开放置与管理页面 |

选中海绵或剪刀工具后，可以专门擦玻璃或修剪水草。屏幕左上角的 DONE 用于放下工具。

## 照料、成长与沙币

喂食、平静地陪伴小鱼、清理玻璃和修剪水草，都会影响鱼缸的长期状态。鱼苗会成长为幼鱼、成鱼和老鱼，每条鱼也会积累自己的行为里程碑。满足下一条鱼苗的条件后，鱼缸会迎来新成员。成长页面的 NEW FRY 会显示还需要完成的条件，HOW? 提供提示。

照料鱼缸可以获得沙币，用来购买水草、装饰、小生物和背景。许多装饰可以调整位置与前后层次。出售按钮需要再次确认，访客和赠送操作也会显示相应提示。

## 灯光、声音与休眠

设置中的 LIGHTS OUT 可以选择双击手动关灯，或选择静置一段时间后自动关灯。VOLUME 调整音量，AUTO FEED 设置鱼缸是否自动投食。

上游支持的开发板通过 PWR 键控制休眠和唤醒，短时间休眠可直接恢复，长时间休眠后会按经过的时间推进饥饿、精力和水草等状态。具体电源键行为请查看对应开发板说明。

按住 BOOT 五秒后再点屏幕，会打开重置确认页。确认 YES 会重新开始鱼缸。

## 联机与访客

两块支持的设备在设置中打开 LINK，按画面引导连接相邻方向后，小鱼可以串门。访客拥有护照，显示名字、外观和家园。可以收藏访客记录，也可以在双方确认后赠送鱼儿。[联机功能说明](tank-link-0.4.md)
