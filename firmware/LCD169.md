# Building for the Waveshare ESP32-S3-(Touch-)LCD-1.69

Built and run with ESP-IDF v6.0.2 on the board (v0.2.0, 2026-09-30). The code keeps the
v5.4 paths behind version guards but has not been built with v5.4.1. From an ESP-IDF shell:

    cd firmware
    idf.py fullclean            # or delete sdkconfig + build/ - old settings would win otherwise
    idf.py -D SDKCONFIG_DEFAULTS="sdkconfig.defaults;sdkconfig.defaults.lcd169" set-target esp32s3 build
    idf.py -p COM5 flash monitor     # your port

The app flash leaves the model partition alone. If the board never had the
model written (e.g. you never used the web installer), write it once:

    python -m esptool --chip esp32s3 -p COM5 write_flash 0x290000 ../model/out/model_q4.bin

What differs from the AMOLED build:
- display: ST7789V2 over SPI; the 448x368 tank is box-filtered down to 280x240 and rotated
- touch: CST816T (reset on GPIO13), coordinates scaled back up to tank space
- power: VBAT by ADC (GPIO1), PWR key = SYS_OUT (GPIO40), power-off = SYS_EN (GPIO41) low
- sound: off (the ES8311 port's I2S pins are this board's LCD pins; the board only has a buzzer)
- screen auto-flip: on, calibrated on the bench (imu_port_qmi8658.c)
