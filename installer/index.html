01 · Connect & install

Bring the update aboard.

Choose the screen on your device. Each board needs its own firmware.

  1. Connect your device to this computer or phone. Use a USB-C data cable (on an Android phone, a USB-C to USB-C cable or an OTG adapter). Wake it with PWR if the screen is asleep.
  2. Click Install update. Choose USB JTAG/serial debug unit (or ttyACM0 on Linux). On Android, Chrome asks for permission to use the USB device; allow it.
  3. Leave it connected until complete. The installer writes approximately {{TOTAL_MB}} MB, then restarts your aquarium.

02 · Make it yours

Pick your atmosphere.

After startup, open Settings → SETTINGS / THEMES in Original. Choose Quiet Lagoon, Tidepool Club or Blackwater, or keep Original.

The settings page looks the same in every theme; its SETTINGS / THEMES title opens the picker. The choice is saved immediately. Meet the new jellyfish in every theme: find it on Upgrades page 5 for 10 sand dollars. Discover new creature and habitat artwork, battery graphics and menus. Watch for occasional surface visits, puffing, ink clouds and electric sparks. Pet names still use the familiar character roll.

A little help.

No device in the USB list?

Try a data cable and another USB port. Press PWR to wake the device. If needed, unplug it, hold BOOT while reconnecting it, then try Install again.

Installing from an Android phone

Chrome on Android has no Web Serial, so this page talks to the board over WebUSB instead. Connect the board with a USB-C to USB-C cable or an OTG adapter, tap Install update, then allow the USB permission Chrome asks for. The board shows up as USB JTAG/serial debug unit. Keep the screen awake and the cable still for the few minutes the write takes. iPhones and iPads cannot install: Safari has neither API.

No permission prompt? Chrome refuses every permission prompt, the USB chooser included, on a page it opened through a certificate warning - and it refuses downloads from such a page too. Two ways out; the first is quickest.

Way 1 - tell Chrome the plain address is fine. On the phone open chrome://flags/#unsafely-treat-insecure-origin-as-secure, type http://…:8765 into its box, set it to Enabled, tap Relaunch, then open this installer over plain HTTP (port 8765, no certificate, no warning) and install from there.

Way 2 - trust this installer's certificate. Download it over plain HTTP (a page with a warning cannot download): aqua-pets-installer.crt. Then on the phone open Settings → Security → More security settings (or Encryption & credentials) → Install a certificate → CA certificate, pick the file from Downloads, and reopen this HTTPS page. The address bar must show a padlock, not a warning.

Either way, try the test below before the install.

Cannot connect?

Close serial monitors and other browser tabs connected to the device. Unplug, reconnect and try again. On Linux, your account may need serial-port permissions.

Opening this remotely

Use HTTPS on port 8766. This local server uses a self-signed certificate; verify the address belongs to your machine before accepting its certificate notice. HTTP on port 8765 is for viewing only, except through localhost.

Alternatively, forward the server to your computer with ssh -N -L 8765:127.0.0.1:8765 alvin@100.66.66.66, then open http://localhost:8765.

Fresh installation / recovery
